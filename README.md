# Закупщик — робот по B2B-площадкам для продаж ПО

Хакатон «ИИкузница» (Softline), задача «Робот по работе с маркетплейсами ПО», трек «Аналитик данных».
Спринт 26.11.2026 10:00 — 28.11.2026 10:00 мск. Код пишется с 10:00 26.11.

## Что делает

Робот сам забирает новые закупки ПО с площадок (MVP: Портал поставщиков Москвы, публичный API), отсеивает
нерелевантное правилами без LLM, затем агент разбирает спецификацию, сопоставляет позиции с каталогом Softline,
проверяет ограничения (нацрежим, «эквивалент не допускается», срок подачи), оценивает сделку и готовит проект КП.
Менеджер получает уведомление в Telegram и на стенде с объяснением, почему сделка интересна, и сам подтверждает цену и КП.
Браузерный плагин показывает разбор на странице закупки на любой площадке. Подачу с ЭП делает только человек.
